# FIND TIA — recherche hors ligne dans les fichiers Office

## Obtenir l'APK (5 minutes, sans installer Android Studio)
1. Créez un dépôt GitHub (ex. `find-tia`) et envoyez-y TOUT le contenu de ce dossier.
2. Onglet **Actions** > **Build APK** > **Run workflow** (ou simple push sur `main`).
3. Quand c'est vert, ouvrez l'exécution > **Artifacts** > téléchargez `FIND-TIA-apk` (zip contenant `app-debug.apk`).
4. Copiez l'APK sur le téléphone, ouvrez-le, autorisez « sources inconnues ».

## Formats lus
Excel (.xlsx .xlsm .xlsb .xls .ods .csv), Word (.docx .docm .dotx : paragraphes, tableaux, zones de texte, en-têtes, pieds de page, notes, commentaires), PowerPoint (.pptx .pptm .ppsx : texte des diapositives + notes), texte (.txt .md).
Anciens .doc / .ppt : à enregistrer d'abord en .docx / .pptx.

## Test rapide sans APK
Ouvrez `www/index.html` dans Chrome : même application.
